☁️ 기기 간 동기화 (Supabase)

확인 중…
1단계 — 연결 정보
Supabase 대시보드 → 프로젝트 → Project Settings → API 에서 두 값을 복사해 붙여넣으세요.
2단계 — 표 만들기 (최초 1회) ✓ 완료됨
Supabase → SQL Editor → 아래를 붙여넣고 Run.
create table if not exists worklog_months ( user_id uuid not null references auth.users on delete cascade, month text not null, data jsonb not null, updated_at timestamptz not null default now(), primary key (user_id, month) ); alter table worklog_months enable row level security; drop policy if exists "own rows" on worklog_months; create policy "own rows" on worklog_months for all using (auth.uid() = user_id) with check (auth.uid() = user_id);
3단계 — 로그인 ← 지금 하실 것
계정이 없으면 그대로 입력하시면 자동으로 가입됩니다. 기기마다 한 번씩만 하면 됩니다.
참고 — anon key 는 공개되어도 되는 값입니다. 실제 방어선은 RLS 정책이라, 로그인한 본인 행만 읽고 쓸 수 있습니다. 로그인 전에는 아무 데이터도 오가지 않습니다.
