# 리뷰 · 제품등록 업무일지

언니의파우치 리뷰 검수 / 제품 등록 건바이건 정산 기록.
리뷰 **건당 500원**, 제품 등록 **건당 600원**.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 본체. **기록이 들어있지 않습니다** |
| `data/log.json` | 실제 기록 (2026-01 ~ 2026-09) |
| `worklog-local.html` | 기록이 들어있는 단일 파일. 더블클릭하면 바로 열림 |
| `.vercelignore` | 배포에서 `data/` 를 제외 |

## 쓰는 방법 두 가지

**① 그냥 파일로 쓰기 (설정 없음)**
`worklog-local.html` 더블클릭 → 끝. 인터넷 없이도 동작하고, 입력한 값은 그 브라우저에 저장됩니다.

**② 주소로 쓰기 (다른 계정·다른 기기에서 접속)**
아래 배포를 한 번 해두면 어느 계정에서든 주소로 들어와 쓸 수 있습니다.

### 배포 (Vercel · 5분, 클릭만)

1. [vercel.com](https://vercel.com) 로그인 → **Add New → Project**
2. 이 저장소 선택 → **Import**
3. 설정 그대로 두고 **Deploy** → 1분 뒤 주소 발급

저장소가 비공개여도 배포됩니다. 코드를 수정해 push 하면 자동으로 다시 배포됩니다.

### 처음 접속했을 때

배포 주소로 들어가면 `data/log.json` 을 읽어 기록이 바로 뜹니다. 별도 설정이 필요 없습니다.
이후 입력한 값은 그 브라우저에 저장되고, **[내보내기]** 로 백업해 저장소에 반영합니다.

## 기록 저장 방식

입력한 값은 **브라우저(localStorage)** 에 저장됩니다. 서버로 아무것도 전송하지 않습니다.

- **[내보내기]** — 백업 JSON 내려받기 → `data/log.json` 에 덮어쓰고 커밋하면 저장소에 남습니다
- **[가져오기]** — 백업 JSON 불러오기 (기기를 바꿨을 때)

브라우저 저장공간을 비우면 기록이 지워지므로, **가끔 [내보내기]로 저장소에 백업**해 두시는 걸 권합니다.

## CMS 바로가기

날짜를 고르면 검수 목록 주소를 만들어 줍니다.

```
https://cms.unpa.me/review/list/all?startDate=YYYY-MM-DD&endDate=YYYY-MM-DD&beforeApproval=true
```

**주소를 만들기만 합니다.** 검수·등록을 대신 실행하지 않고 아무것도 자동으로 누르지 않습니다.
운영 환경에 직접 반영되는 작업이라 사람이 직접 열어 확인하고 처리하도록 링크 생성까지만 두었습니다.

## 공개 범위

이 저장소는 현재 **공개(public)** 입니다. `data/log.json` 과 커밋 이력에 실제 수입 기록이
들어 있으므로, 주소를 아는 사람은 누구나 열람할 수 있습니다.

비공개로 바꾸려면 **Settings → Danger Zone → Change visibility → Private**.
비공개 저장소도 Vercel 무료(Hobby) 플랜에서 정상적으로 자동 배포됩니다.
다만 **배포된 주소 자체는 비공개 저장소여도 여전히 공개**이므로,
그때는 `.vercelignore` 의 `data/` 주석을 해제해야 실제로 가려집니다.
