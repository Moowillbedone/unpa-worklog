🧭 리뷰 검수 콘솔

클릭 말고 끌어다 놓기 · 즐겨찾기 바 Cmd/Ctrl+Shift+B

쓰는 법 — cms.unpa.me 어느 화면에서든 클릭 → 패널에 날짜 입력 → [스캔 시작] → 대기열에서 [👀 사진 보고 일괄 승인]으로 승인분을 처리하고, 수정요청·미노출은 [체크한 것 실행]. 스캔은 조회만이고 실제 처리는 확인창을 눌러야 나갑니다. 끝나면 처리 로그가 내려받아집니다.
👀 일괄 승인 화면 — 대상 사진을 한 화면에 깔아 줍니다. 전부 검수완료로 선택된 채 열립니다. 카드를 누르면 건너뛰기, 💄를 누르면 발색샷 요청으로 바뀝니다. 🔍는 그 리뷰의 사진 전부를 크게 보여줍니다. 발색 제품은 자동으로 맨 앞에 정렬되니 그 구간만 주의해서 보면 됩니다.
사진 자동판별의 한계 — 화면캡처·저해상은 전량이 그럴 때만 미노출 후보가 됩니다. 직접촬영이 한 장이라도 섞이면 자동 처리하지 않고 사람 확인으로 넘깁니다. "직접 찍었는데 제품과 무관한 사진"(예: 육회)은 기계가 못 걸러내니 그리드에서 눈으로 판단하세요.
업무일지 연동 — 처리 후 [📒 업무일지 반영]이 건수를 넘겨 주고, [검수기록 JSON]을 받아 업무일지 [검수 기록] 탭에서 [판정 결과 불러오기]로 올리면 건별 내역이 날짜별로 쌓입니다.

03 · 판정 기준

상황판별 방법처리
엑박 (제품 매칭 실패)productId 없음 · productPrice 비어 있음 · 제품 이미지가 null브랜드/제품 검색으로 아래 3갈래
└ 브랜드○ 제품○상품명이 정확히 일치(유사도 0.8 미만은 제외)제품 재선택 요청 일괄 실행
└ 브랜드○ 제품✗브랜드는 있으나 그 안에 제품 없음상품등록 필요 — 사람이 직접
└ 브랜드✗브랜드 자체가 CMS에 없거나 미검수브랜드+상품 등록 — 사람이 직접
무의미한 본문자모 나열(ㅁㄴㅇㄹ) · 같은 글자 반복(가가가거거) · 동일 음절 반복미노출
본문 도배같은 문장 반복 · 실질 내용 극소미노출
화면캡처 / 저해상알려진 폰 해상도 ±4px · 가장 긴 변 1000px 이하전량이 그럴 때만 미노출
의심 사진 혼재직접촬영과 저해상·캡처가 섞여 있음자동 처리 안 함 · 그리드에서 판단
발색 제품제품명에 립·아이·베이스·네일 색조 키워드그리드에서 💄 눌러 발색샷 요청
사진 무관제품과 상관없는 사진 (기계가 못 걸러냄)그리드에서 눈으로 판단
검수 대상 규칙 — ① 브랜드 안에 CMS에 존재하는 상품이 매칭돼 있고, ② 좌상단 제품 이미지가 엑박이 아니어야 검수 대상입니다. ③ 무의미한 본문만 있으면 검수 대상이 아니라 미노출, ④ 발색 있는 제품인데 발색샷이 없으면 발색샷 요청입니다. 그래서 👀 그리드에는 ①②③을 이미 통과한 건만 올라옵니다 — 전부 훑을 필요 없이 이상한 것만 골라내면 됩니다.
기계가 다 하지는 못합니다. 사진 판별은 해상도만 봅니다(파일 크기는 보지 않습니다). 사진이 제품과 맞는지, 발색샷이 실제로 있는지는 픽셀을 봐야 알 수 있어 그리드에서 사람이 판단합니다. 되돌리기 어려운 미노출은 좁게(상한 30), 되돌리기 쉬운 검수완료는 넓게(상한 300) 잡아 두었습니다.

04 · 수정요청 템플릿

수정요청/발색샷 안내 문구입니다. templates.json에 저장되며, 적용기(자동 처리)가 이 문구를 그대로 가져다 씁니다. [{제품명}]은 실제 제품명으로 자동 치환됩니다.
